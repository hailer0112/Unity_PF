# 뒤틀린 동화 – 프로젝트 소개

## 1. 개발 환경

| 항목 | 내용 |
|---|---|
| 개발 엔진 | Unity 6 |
| 개발 언어 | C# |
| 개발 인원 | 1인 |
| 지원 플랫폼 | Windows PC, Web |
| 입력 방식 | 키보드 및 마우스 |

## 2. 플랫폼별 구현

### Windows PC
- 키보드 및 마우스 기반 조작 구현
- 플레이어 이동, 공격, 스킬 사용 기능 적용
- Windows 실행 파일 빌드 완료

### Web
- Unity Web 플랫폼 빌드 완료
- 브라우저 실행을 위한 빌드 파일 생성
- 로컬 웹 서버를 통한 실행 확인 필요

## 3. 주요 구현 기능

- 마우스 우클릭 이동 및 좌클릭 공격
- QWER 스킬과 Space 대시
- 몬스터 AI 및 보스 전투
- HP, 스킬 UI 및 공격 전조 표시

## 4. 빌드 및 테스트

Windows PC와 Web 플랫폼을 대상으로 빌드를 진행

PC 빌드는 실행 파일을 생성하였으며, Web 빌드는 HTML 및 관련 리소스 파일을 생성
